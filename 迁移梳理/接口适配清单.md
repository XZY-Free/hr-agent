## 0. 认证模式（所有业务接口前置）

每个业务调用前都先获取 JWT，流程为：

```
POST /identity/api/v1/oauth  →  响应 {"result":true, "code":200, "data":"<JWT>"}
→ 业务请求带 Header: Authorization: Bearer <JWT>
```

JWT 响应解析逻辑（FastGPT 代码节点原文）：

```javascript
function main({response}){
    var flag = false, jwt = "", errorMsg = "";
    try {
        var dataJson = JSON.parse(response);
        if(dataJson.result && dataJson.code == 200) {
            jwt = dataJson.data; flag = true;
        } else {
            errorMsg = "获取盖亚JWT权限失败，message=" + dataJson.message;
        }
    } catch(e) {
        errorMsg = "获取盖亚JWT权限失败，JSON格式错误，json=" + response;
    }
    return { flag, jwt, errorMsg };
}
```

> 迁移建议：JWT 有有效期，迁移后应在服务端缓存复用，不要每次业务调用都重新获取。

| 项 | 值 |
|---|---|
| URL | `https://openapi.gaiaworkforce.com/identity/api/v1/oauth`（生产）<br>`https://openapi-s.gaiaworkforce.com/identity/api/v1/oauth`（沙箱） |
| Method | POST |
| Content-Type | `application/x-www-form-urlencoded` |

**Form 参数：**

| 参数 | 值 | 说明 |
|------|-----|------|
| grant_type | `{全局变量.grant_type}` | 渠道注入 |

**响应：** `{"result": true, "message": "Api access succeeded", "data": "eyJ0eXA....", "code": 200}`，`data` 即 JWT。

{

## 6. 查询排班数据

| 项 | 值 |
|---|---|
| URL | `https://openapi-s.gaiaworkforce.com/wfm4customization/api/v1/scheduling/attendance/getScheduleData` ⚠️ 沙箱 |
| Method | POST |
| Content-Type | JSON |
| Headers | `Authorization: Bearer {jwt}`、`tenant: snowbeertest` ⚠️ 注意：此处 tenant 是硬编码的 `snowbeertest`，未用 corp_id 变量 |

**请求体（3 个调用点，日期范围不同）：**

```json
{
  "size": "30",
  "startDate": "{全局变量.startDate 或 代码节点拆分出的日期}",
  "endDate":   "{全局变量.endDate 或 代码节点拆分出的日期}",
  "unitCode": "",
  "employeeId": "{全局变量.employeeId}",
  "page": "1",
  "isIncludeSubUnit": false
}
```

**用于：** 测试-获取排版信息（非快捷请假 C 线内）。分 3 段日期范围查询后合并（拆分日期#5 节点），用于核算实际请假天数、判断休息日/班次时间。

**⚠️ 适配注意：** 该节点 headers 里还带了一串 Apifox 调试头（`User-Agent: Apifox/1.0.0`、`Host`、`Connection` 等），是从 Apifox 复制配置时带入的，迁移时应清理，只保留 `Authorization` 和 `tenant`。

## 7. 渠道注入变量（调用方需提供）

| 变量 | 说明 |
|------|------|
| employeeId | 当前登录员工在盖亚的人员 ID |
| corp_id | 盖亚企业租户 ID（同时用于 URL 路径与 tenant 头） |
| client_secret | 盖亚开放平台应用密钥 |
| grant_type | OAuth 授权类型（固定值，需向盖亚确认，通常为 client_credentials 类） |

> ✅ 2026-07-25 业务确认：迁移后**沿用此传值方式**，由后端调用智能体时传入这 4 个变量。
